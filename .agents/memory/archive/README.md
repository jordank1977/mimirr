# Memory Archive

This directory stores finished or retired project memory topic files.

## Archival Rules
1. **Preserve Standing Facts First**: Before archiving a file, copy any permanent architectural constraints, traps, or runbooks that still apply into an active topic file under `.agents/memory/`.
2. **Remove Index Pointers**: Once moved here, delete the topic's pointer line from `.agents/rules/memory-index.md` so the active index remains lean (< 200 lines).
3. **Record Migration Below**: Add an entry to the Archive Log detailing what was moved, the date, and where any remaining standing facts were placed.
